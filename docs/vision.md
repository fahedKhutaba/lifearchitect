# Vision

## One line

An AI-powered personal operating system that helps people define goals, create plans, track execution, and continuously improve across all areas of life.

Not a habit tracker. Not a task manager. Not a note-taking app.
**Personal Architect + Coach + Memory + Planning System.**

## Domains

### Goals

Goal definition, decomposition, milestones, progress tracking.
_Examples: become an AI Architect · complete an MSc · prepare a horse for competition · improve physical fitness._

### Execution

Tasks, habits, routines, checklists — the bridge between goals and daily work.

### Knowledge

Personal knowledge base: notes, documents, books, meeting summaries, learning material. The future RAG layer.

### Planning

Calendar, activities, family plans, work commitments.
_"Given my calendar next week, what should I focus on?"_

### AI Coaching

Specialized coaches — career, learning, health, family. Later, separate agents.

## The real project

LifeArchitect is an **AI-native personal operating system built by an AI-native engineering organization**:

- **Product goal** — build LifeArchitect.
- **Experiment goal** — learn how to orchestrate a team of AI agents to design, build, test and evolve a software product.
