# Roadmap

Versions, not dates. Each version ships only when the previous one is stable.

## Phase 0 — Build the team

- Repository, CI, GitHub workflow
- IDE and tooling setup
- Agent team definitions and scopes
- Activity log and build-log metrics
- Dry run: one tiny feature through the whole team

## V1 — Weekly targets (no AI)

- Set weekly targets (e.g. 5 h sport per week) and log progress during the week
- "This week" dashboard: progress, pace status, weekly score, trend
- Responsive web app (mobile app later)
- Scope: [`docs/product/v1-scope.md`](product/v1-scope.md)

## V1.x — Goals and habits

- Goals, milestones, tasks; targets optionally linked to goals
- Habits with schedules contributing to targets
- Sports watch integration (Garmin)

## V2 — AI Goal Assistant

- Goal decomposition: _"I want to become an AI Architect"_ → learning plan, milestones, reading list, projects
- Progress insights
- Claude API, single provider

## V3 — Knowledge

- Notes, documents, search
- RAG
- MCP server exposing LifeArchitect to Claude

## V4 — Coaching

- Specialized coaching agents (career, learning, health, family)
- Multi-agent workflows
- Optional AI gateway (multiple providers)

## Later

- Mobile app (React Native + Expo)
- k3s deployment
- Calendar integration
